# Move It Website

A responsive landing page for a fictional moving company built using Bootstrap.

## Features

- Responsive layout
- Bootstrap grid system
- Cards
- Navigation bar
- Hero section
- Footer

## Technologies

- HTML5
- CSS3
- Bootstrap 5

## Setup

1. Clone the repository.

2. Open `index.html` in your browser.

## Note

This project was built as part of Angela Yu's **100 Days of Code: The Complete Python Pro Bootcamp** to practice Bootstrap and responsive web design.
