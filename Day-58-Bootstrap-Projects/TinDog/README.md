# TinDog Landing Page

A responsive landing page for a fictional dog dating platform built using Bootstrap.

## Features

- Responsive layout
- Bootstrap components
- Navigation bar
- Pricing section
- Testimonials
- Call-to-action section
- Footer

## Technologies

- HTML5
- CSS3
- Bootstrap 5

## Setup

1. Clone the repository.

2. Open `index.html` in your browser.

## Note

This project was built as part of Angela Yu's **100 Days of Code: The Complete Python Pro Bootcamp** to practice Bootstrap and responsive web design.
