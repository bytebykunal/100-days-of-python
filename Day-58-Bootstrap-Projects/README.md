# Day 58 - Bootstrap Projects

This folder contains two Bootstrap projects completed as part of Day 58 of Angela Yu's **100 Days of Code: The Complete Python Pro Bootcamp**.

## Projects

- **TinDog** – A responsive landing page for a fictional dog dating platform.
- **Move It** – A responsive landing page for a fictional moving company.

Both projects were built to practice Bootstrap components, responsive layouts, and modern web design.
