# Personal Portfolio Website

A personal portfolio website built with Flask by customizing a responsive HTML5 template. The project showcases personal information, a profile photo, and social media links.

## Features

- Responsive personal portfolio website
- Customized with my own profile picture
- Personalized name and information
- GitHub and Instagram profile links
- Clean and modern design
- Built using Flask

## Technologies

- Python 3.14
- Flask
- HTML5
- CSS3

## Project Structure

```
Day-56-Personal-Portfolio/
│
├── server.py
├── templates/
├── static/
├── assets/
├── README.md
└── requirements.txt
```

## Setup

1. Clone the repository.

2. Install the required dependency:

```bash
pip install -r requirements.txt
```

3. Run the Flask application:

```bash
python server.py
```

4. Open your browser and visit:

```
http://127.0.0.1:5000/
```

## Note

This project is based on the portfolio template provided in Angela Yu's **100 Days of Code: The Complete Python Pro Bootcamp**. I customized the template by adding my own profile photo, personal information, and social media links.
